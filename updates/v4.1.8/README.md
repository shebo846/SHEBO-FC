# SHEBO FC 4.1.8 — крупное обновление

Статус: подготовка обновления. Это рабочая спецификация, а не заявление о готовности функций.

## Цель
Сделать матчевую часть SHEBO FC заметно ближе к телевизионной подаче футбольных игр FIFA, улучшить читаемость матча и заложить основу для следующих обновлений.

## Приоритеты
1. Телевизионная камера матча.
2. Оптимизация графики под слабые и более мощные ПК.
3. Улучшение игрового интерфейса.
4. Переключаемые схемы управления.
5. Настройки меню и звука.
6. Подготовка технической базы для карьеры, составов и онлайна.

## Важно
Для реализации игровых изменений необходим полный исходный проект игры. Установочный архив и файл app.asar сами по себе не заменяют исходники проекта и не гарантируют возможность безопасно изменить игровую логику.
