# SHEBO FC — Updates

Здесь хранятся материалы всех обновлений игры SHEBO FC.

## Правила
- Каждое обновление получает отдельную папку: `v4.1.8`, `v4.1.9` и т.д.
- В папке версии хранятся описание изменений, связанные файлы и инструкции.
- Готовые установщики Windows публикуются как артефакты GitHub Actions или в Releases.
- Исходный код игры и проектные ресурсы должны храниться отдельно от готовых установщиков.
